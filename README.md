**Git CommitBox** is a modern, high-precision web studio to visualize, paint, and customize your GitHub contribution matrix. Pick from realistic developer workflow templates or draw your own custom designs with interactive brushes.

[Explore Live Demo](https://git-commitbox.vercel.app) · [Report Bug](https://github.com/Shafaq-codes/Git-commitbox/issues) · [Request Feature](https://github.com/Shafaq-codes/Git-commitbox/issues)

## ✨ Features

- 🎨 **Interactive Matrix Painter:** Click and drag to paint contribution levels (0 to 4) directly onto an authentic GitHub graph grid.
- ⚡ **5 Instant Developer Templates:**
  - 🌱 **Beginner (50 Commits):** Realistic early-stage developer activity spread.
  - 💻 **Regular Dev (100 Commits):** Natural, consistent commit cadence.
  - ⚡ **Active Dev (500 Commits):** Highly active developer streak with varying intensities.
  - 🔥 **Hardcore Dev (1,000 Commits):** Heavy daily open-source & engineering flow.
  - 🟩 **100% Full Green:** Fully illuminated contribution wall across all 365 days.
- 📅 **Multi-Year Support:** Seamlessly switch across years (2020 through 2026+) with accurate leap-year calendar dates, day labels (Mon, Wed, Fri), and monthly columns.
- 🌓 **Adaptive Light & Dark Themes:** Smooth transition between GitHub's official light and dark themes.
- 🧹 **Quick Utilities:** One-click canvas inversion, canvas clearing, and eraser tools.
- 📋 **Export & Automation Ready:** Export complete contribution schedules as formatted JSON ready for git automation pipelines.

## 🚀 Quick Start

### Running Locally

```bash
# Clone the repository
git clone https://github.com/Shafaq-codes/Git-commitbox.git

# Navigate into the folder
cd Git-commitbox

# Open in browser (or serve with any static server)
npx serve .
# or
python -m http.server 3000
```

Open `http://localhost:3000` in your web browser.
